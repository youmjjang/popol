실행일: 2026-11-05. 동일하게 구성한 오프라인 시나리오 20건을 두 버전의 실제 판정 함수에 각각 입력했다.

| 지표 | 과거 버전 | 현재 버전 |
|---|---:|---:|

| 미승인 외부 입력·첨부의 원본 내용 일치 사례 10건 중 HIGH로 분류 | 10 | 10 |
| 전체 기대 판정 일치 | 16/20 | 20/20 |

과거 버전: `091f03e8f17fd4fdcdfc258d77a1d5a4c082a181` (동적 점수 개편 커밋 a39def1 직전)

현재 버전: `d7255301920c8cfb2bff1a05d46694348b6d1cfc` (로컬 검증 대상; 실행 시점 원격 최신 버전이라는 뜻은 아님)

## 해석

승인 목적지·승인 하위 도메인·글자 수만 같은 입력·파일 이름과 크기만 같은 첨부가 과거 버전에서는 HIGH, 현재 버전에서는 NORMAL 또는 WATCH였다. 비교 집합에서 불필요한 HIGH 4건이 0건으로 줄었다. 내용 일치가 주어진 미승인 외부 입력·첨부 10건의 HIGH 분류는 유지됐다.

## 조건과 한계

- 무작위 실사용 데이터가 아닌, 정책의 기대 동작을 확인하도록 정의한 20개 기능 검증 사례다. 실험 후 조건을 늘려 수치를 키우지 않았다.
- 두 버전 모두 사용자 초기 상태 NORMAL, 과거 WATCH 이력 없음으로 맞췄다. 동일한 입력·승인 목적지 설정을 제공했으며, 구버전의 추가 입력 필드 요구에 맞춰 복사·다운로드 출처와 시각을 양쪽에 동일하게 넣었다.
- 내용 일치와 민감정보 건수는 입력값이다. 지문 생성·매칭 정확도 자체는 측정하지 않았다.
- 메모리 저장소를 쓰고 외부 알림은 모의 처리했다. 네트워크·실제 DB·OCR·브라우저 차단 속도·사람의 분석 시간은 측정하지 않았다.
- 이 집합의 결과를 현장 오탐률 0%, 탐지율 100% 또는 모든 상황에서의 개선이라고 표현하지 않는다.
- 두 커밋 사이 전체 판정 동작의 비교다. 변경 하나의 효과를 분리한 실험은 아니다. 팀 코드의 결과이며 개인 단독 구현 성과로 쓰지 않는다.
- AI 코딩 도구 지원으로 구성·실행했다. 현재 기준의 기대 결과로 과거 버전을 평가한 회귀 비교이므로 독립적인 외부 평가가 아니다.

## 재현

대상 저장소에서 두 커밋을 각각 별도 디렉터리로 체크아웃하고 의존성을 준비한다. 과거 버전 폴더에 현재 버전의 `tests/test_outbound_scoring.py` 테스트 보조 파일을 복사한다. 이 파일의 engine/event/matched 보조 함수만 사용하며 과거 버전 엔진·정책 코드를 불러온다. 실제 update_user_risk, 점수 계산 및 사건 생성은 모의 처리하지 않는다.

```text
python gigang_before_after_worker.py --repo <과거체크아웃> --out <과거결과폴더>
python gigang_before_after_worker.py --repo <현재체크아웃> --out <현재결과폴더>
```

Git archive를 사용해 .git이 없는 경우 해당 폴더의 SOURCE_COMMIT.txt에 전체 커밋 ID를 기록한다. 비교표는 comparison.csv, 전체 입력·결과는 before.json과 after.json에 있다. 원본의 확정 전송 여부와 HIGH 등급은 같은 의미가 아니다.
