# 김유미 포트폴리오 (popol)

기존 `youmjjang-lab` 포트폴리오의 **디자인, 프로젝트 카드 5개, 프로젝트 상세 페이지, 화면 자료**를 최대한 그대로 가져온 GitHub Pages 사이트입니다.

- **사이트:** https://youmjjang.github.io/popol/
- **원본 디자인:** https://github.com/youmjjang/youmjjang-lab
- 바꾼 부분: 첫 화면과 소개에서 데이터 분석 직무를 강조하던 문구를 중립적인 개발 포트폴리오 소개로 수정
- 그대로 유지한 부분: 레이아웃, 컬러, 카드/필터/상세페이지와 프로젝트별 구현 기록
- 실제 이미지: 원본 공개 GitHub 저장소의 스크린샷을 참조
- 실행: `index.html`을 열거나 `python -m http.server 8000`
- 배포: `main` 브랜치 `/(root)` GitHub Pages

팀 프로젝트와 개인 프로젝트는 원본처럼 구분하며, 실제로 사용하지 않은 Java/Spring 기술을 추가하지 않았습니다.
