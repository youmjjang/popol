# 김유미 개발 포트폴리오

GitHub Pages로 배포하는 **일반 웹사이트형 포트폴리오**입니다.

## 사이트

https://youmjjang.github.io/popol/

## 구성

- 상단 메뉴: 소개 / 기술 / 프로젝트 / 링크
- **GIGANG (기강)**: 보안 관제 팀 프로젝트
- **쉬엄쉬엄**: 주변 휴식공간 검색 웹 서비스
- **오늘의짐**: 물품보관함과 이동 동선을 비교하는 팀 프로젝트
- 각 프로젝트는 실제 화면, 간단한 소개, 주요 기능, 사용 기술, GitHub/서비스 링크를 보여줍니다.

## 파일

- `index.html`: 모든 웹 콘텐츠
- `styles.css`: 화면 스타일과 모바일 반응형 디자인
- `.nojekyll`: GitHub Pages 정적 파일 배포용

별도 PPT/슬라이드 페이지나 JavaScript 프레임워크는 사용하지 않습니다.

## 실행 및 배포

`index.html`을 브라우저로 열거나 GitHub Pages에서 `main` 브랜치, `/(root)` 배포 설정으로 게시합니다. HTML/CSS를 수정하고 main에 커밋하면 GitHub Pages에 다시 배포됩니다.

## 사실 표기

- 팀 프로젝트는 팀 프로젝트로 구분하고, 확인된 참여 작업만 설명합니다.
- Java/Spring Boot를 사용하지 않은 프로젝트를 해당 기술 경험으로 표기하지 않습니다.
- 화면 사진은 실제 프로젝트 GitHub 저장소의 공개 이미지를 사용합니다. 원본 파일을 옮기면 이미지 주소도 업데이트해야 합니다.
- 쉬엄쉬엄과 오늘의짐의 외부 데이터는 실시간 이용 가능 상태를 항상 보장하는 것은 아닙니다.
