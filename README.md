# popol — 김유미 개발 포트폴리오

테나아이 AI 서비스 백엔드 신입 지원을 위해 구성한 11페이지 분량의 **웹·인쇄 겸용 포트폴리오**입니다.

- 프로젝트 순서: **GIGANG(기강) → 쉬엄쉬엄 → 오늘의짐**
- 팀 프로젝트와 개인 구현 내용을 구분하여 기술합니다.
- Java/Spring을 사용하지 않은 프로젝트를 Java/Spring 개발 경험처럼 표현하지 않습니다.
- 기존 프로젝트의 실제 스크린샷을 공개 GitHub 저장소에서 불러옵니다.

## 열기

[포트폴리오 HTML](./index.html) 파일을 열거나, GitHub Pages에서 `main / (root)`를 선택해 정적 사이트로 게시하세요.

오른쪽 상단 **PDF로 저장 / 인쇄** 버튼을 누르면 브라우저 인쇄 창이 열립니다. 용지는 **A4 가로**, 배경 그래픽 인쇄를 선택하면 인쇄용 11장 포트폴리오가 만들어집니다.

## 구성

- `index.html` — 페이지별 내용 및 실제 프로젝트 화면
- `styles.css` — 화면용 스타일, A4 가로 인쇄용 레이아웃
- `script.js` — 이전·다음 페이지 탐색, 인쇄 기능

## 검증 기준 및 안내

- 기강은 팀 프로젝트입니다. 개인 기여는 기존 상세 문서에 기록된 **이벤트 수집·연동, DB 연결, 위험도 판단 흐름 보완** 중심으로 표현했습니다.
- 기강 캡처의 숫자는 테스트 당시의 화면 값이며 실제 고객사 운영 실적이 아닙니다.
- 쉬엄쉬엄의 위치·경로는 외부 지도 데이터 및 API 상태에 의존합니다.
- 오늘의짐의 물품보관함 정보는 데이터 제공 범위에 제한이 있고 실시간 빈자리 여부를 보증하지 않습니다.
- 이미지의 원본은 `youmjjang-lab`과 `About-me` 공개 저장소에 보관되어 있어 저장소 변경 시 링크 수정이 필요합니다.
